# shinji-theme
概要

このプロジェクトは、自身のポートフォリオサイト用に開発した自作 WordPress テーマです。

単なるテンプレート利用ではなく、WordPress のテーマ構造を理解しながら、PHP を用いてゼロから制作しています。

また、Web 制作だけでなく、Linux サーバー構築や HTTPS 化などのインフラ構築も含めて自分で行っています。
制作目的

このポートフォリオでは以下のスキルを実践的に学習・実装することを目的としています。

    WordPress テーマ開発
    PHP / HTML / CSS / JavaScript
    Linux サーバー運用
    Apache 設定
    HTTPS(SSL)化
    Git / GitHub によるソースコード管理
    VPS 上での公開運用

主な機能
